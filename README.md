## 📖 About The Project

GitHub Issues Tracker is a simple yet powerful web application that helps users track, manage, and organize GitHub issues efficiently with a clean and modern UI.

The application is inspired by the workflow of GitHub Issues, which are widely used for tracking bugs, feature requests, and project tasks. :contentReference[oaicite:0]{index=0}

# ⚙️ Installation & Setup

## Clone the repository

```bash
git clone https://github.com/your-username/github-issues-tracker.git
```

## Navigate to project folder

```bash
cd github-issues-tracker
```

## Install dependencies

```bash
npm install
```

## Run the project

If using Live Server:

```bash
Right Click → Open with Live Server
```

Or if using Vite / npm:

```bash
npm run dev
```
